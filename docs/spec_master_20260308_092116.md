## 2026-03-08 Current Specification

### Core
- [1] 目的: チャット中心でタスク/メモ/数値集計/利益計算を操作する秘書型Webアプリ。
- [2] AI連携: 現在は非AIルールベース応答。設定上は将来AI API接続可能な構成。
- [3] 実行基盤: Node.js（標準httpサーバー）、静的配信 + JSON API。
- [4] ポート: `3000`（`PORT` 環境変数で変更可）。
- [5] リマインダー監視: 30秒間隔でタスク通知判定（`REMINDER_CHECK_MS = 30 * 1000`）。

### Folder/Files
- [6] 主要保存先: `data/store.json`（全状態を永続化）。
- [7] ログ: `logs/latest.log`（横断）と `logs/runs/<run_id>.log`（実行単位）。
- [8] フロント: `public/*.html`, `public/*.js`, `public/styles.css`。
- [9] 運用資料: `docs/`、進捗記録: `progress/`。

### Pages
- [10] チャット: `/`（固定ヘッダー/固定フッター、チャット領域のみスクロール）。
- [11] タスク管理: `/tasks.html`（一覧/編集/削除/完了/再開/ソート）。
- [12] メモ一覧: `/memos.html`（一覧/編集/削除/ソート）。
- [13] 数値集計: `/number-tool.html`（入力、KPI、履歴、編集/削除、レイアウト設定）。
- [14] 利益計算: `/profit-tool.html`（入力、結果、履歴、編集/削除）。
- [15] 利益設定: `/profit-settings.html`（送料/梱包候補、表示順設定）。
- [16] 通知設定: `/notify.html`（端末通知許可の専用画面）。
- [17] 共通設定: `/settings.html`（AI設定、通知タイミング設定）。
- [18] アイコン設定: `/icon-settings.html`（画面別アイコンURL差し替え）。
- [19] 使い方: `/help.html`。

### Chat UX / Layout
- [20] チャットUIは左右バブル表示（ユーザー右、秘書側左）。
- [21] 送信欄は1行固定（LINE風）で、送信ボタンと同列。
- [22] モード終了ボタンはフッター上部に固定表示（モード時のみ）。
- [23] メニューはハンバーガー + カテゴリツリー（グループ化）で表示。
- [24] 主要カテゴリ: メイン/タスク/メモ/数値集計/利益計算/共通設定。
- [25] スマホ時の上部操作は「既存MENUボタンと同じレイヤー」に横並びで表示する（`MENU + 画面固有ボタン + 閉じる`）。
- [26] 上部横並びボタンは同サイズで統一する。

### Chat Mode / Intents
- [25] モード: `normal` / `task_create` / `memo`。
- [26] `タスク作成` で task_create モードへ。
- [27] `メモ作成` または `メモ` で memo モードへ。
- [28] `通常モード` / `モード終了` で normal に戻る。
- [29] normal モードでは機能メニューを案内（将来AI会話モード化予定）。
- [30] 曖昧な呼び出し語に対応して各画面への遷移アクションを返す。

### Task Function
- [31] 自然文からタスク候補（件名/担当/期限/通知設定）を作成。
- [32] 候補は in-chat の `承認/編集/見送り` で操作。
- [33] 承認時にタスク登録、`taskNo` を自動採番。
- [34] タスク編集: 件名/担当/期限文/通知設定の更新。
- [35] タスク削除、完了、再開をAPI経由で実施。
- [36] タスク管理画面で `ステータス/期限/担当者` ソート。

### Reminder / Notification
- [37] 通知は期限起点（N日前/N時間前/当日HH:mm/期限時刻/期限後スヌーズ）。
- [38] 未完了の間は通知継続。通知履歴は `store.reminders` に保存。
- [39] チャットへ通知文を自動投稿。
- [40] 端末通知はブラウザ Notification API を使用（許可後）。
- [41] 端末通知UIはチャット本体ではなく `/notify.html` で管理。

### Memo Function
- [42] memoモード中の発話はメモとして保存（`notes`）。
- [43] メモ一覧画面はノートアプリ風カードUI。
- [44] メモは編集/削除可能。
- [45] ソートは `更新順/作成順/本文順` と昇降順に対応。

### Number Tool Function
- [46] 数値 + タイトルを連続記録。
- [47] KPI: 合計/件数/平均を表示。
- [48] 履歴は編集/削除/全消去に対応。
- [49] レイアウト設定: `KPI/フォーム/要約/履歴` の順序を保存可。

### Profit Tool Function
- [50] 入力項目: 商品名、原価、手数料率、送料、梱包、売価、その他。
- [51] 出力項目: 利益、利益率、総コスト、明細テキスト。
- [52] 履歴は保存・編集・削除可能。
- [53] 利益設定画面で送料候補・梱包候補を編集可能。
- [54] レイアウト設定: `フォーム/結果/履歴` の順序を保存可。

### Config / Settings
- [55] AI設定: enabled/provider/model/baseUrl/apiKey/apiSecret。
- [56] 通知設定: daysBefore/hoursBefore/sameDayTimes/atDue/overdueSnoozeMinutes。
- [57] アイコン設定: 画面ごとのアイコンURLを保存し表示に反映。

## ミニアプリ共通ヘッダー基本設計（固定運用）
本プロジェクトで新規ミニアプリを作る際は、以下のヘッダー仕様を基本設計として統一する。

- モバイルヘッダーは `mobile-top-row` を使用し、左から右へ次順で配置する。
  - `MENU`
  - ページ遷移タブ（例: 履歴 / 設定 / 位置変更）
  - `×`（右端の丸ボタン）
- `×` は必須。
  - 形状: 真円
  - 配置: ヘッダー最右
  - 表示: 常時
- タブボタン仕様。
  - 現在ページ: アクティブ色（塗り）
  - 非アクティブ: 白背景（ホワイトアウト）
  - 文字色: 白系（視認性確保）
- `位置変更` ボタンはホーム画面（メイン画面）でのみ表示。
- `MENU` のサイズ/デザインは全ページ共通。
  - 左詰め表示
  - ページごとに見た目を変えない
- `nav.js` の `mountMobileTopRow()` で `MENU`・タブ群・`×` を同一レイヤーで横並び構築する。

  - スタンドアローン版はアプリ内遷移で完結
  - chatbot連携版はメインの `×` で chatbot へ戻る

## 共通UI仕様（row移動システム）
次のミニアプリを作る際は、フォーム並び替えの標準操作として本仕様を共通適用する。

- 位置変更は `位置変更モード` の ON/OFF で切替える。
- 位置変更モード中のみ、各 `row` の左側に縦3点ハンドルを表示する。
  - 3点は文字列ではなくデザイン要素（同系色の単色）で描画する。
  - 3点は `row` 内に自然に収まる位置とし、項目名との間隔を確保する。
- `row` 並び替え操作は `長押しドラッグ&ドロップ` を標準とする。
  - 長押しで `row` 全体が浮き上がる視覚フィードバックを出す。
  - ドラッグ中は `row` 全体が移動対象であることを明示する。
- 位置変更モード中は入力操作を無効化する。
  - 入力欄/選択欄を編集できない状態にし、移動操作へフォーカスする。
  - iOS長押し時の選択メニュー（コピー等）は抑止する。
- セクション移動ボタンの境界制御を行う。
  - 最上段セクションでは `↑` を非活性化。
  - 最下段セクションでは `↓` を非活性化。
  - 非活性時は見た目で判別できるようにする。
- 並び順はUI設定として保存し、再読み込み後も再現する。
