## 1. 画面の役割

- URL: `/profit-tool.html`
- 役割:
  - 入力項目を設定
  - 利益額・利益率・ROI・内訳を確認
  - 計算結果を保存

### 1-2. 履歴
- URL: `/profit-history.html`
- 役割:
  - 保存済みの計算結果一覧

  - 削除

### 1-3. 設定
- URL: `/profit-settings.html`
- 役割:
  - 表示設定（右詰め/左詰めなど）
  - 送料候補、梱包材候補の追加/編集/削除
  - 先頭行で `設定保存` と `マニュアル` を操作

### 1-4. マニュアル
- URL: `/profit-manual.html`
- 役割: ブラウザ上で手順をいつでも参照

## 2. 基本操作（商品Aの例）
ここでは以下の仮データで実施します。

| 項目 | 入力値 |
|---|---|
| 商品名 | 商品A |
| 原価 | 550 |
| 手数料（%） | 10 |
| 送料（選択） | ネコポス（185円） |
| 梱包資材代（選択） | 封筒/袋（50円） |
| 販売予定価格 | 1,799 |
| その他 | 0 |

### 2-1. 入力
1. `商品名` に `商品A` を入力。  
2. `原価` に `550` を入力。  
3. `手数料（%）` は `10` を入力。  
4. `送料` で `ネコポス（185円）` を選択。  
5. `梱包資材代` で `封筒/袋（50円）` を選択。  
6. `販売予定価格` に `1799` を入力。  
7. `その他` は `0` を入力。  

### 2-2. 計算
1. `計算` ボタンを押します。  
2. 画面中央に `計算しました。` の通知が表示されます。  
3. 結果エリアが更新されます。

### 2-3. 期待される結果（商品A）
計算ロジック（現行実装）:
- 手数料額 = 売価 × 手数料率 = `1799 × 10% = 179.9`（表示時は `180円`）
- 総コスト = `floor(原価 + 手数料額 + 送料 + 梱包材 + その他)`
- 利益額 = `floor(売価 - 総コスト)`
- 利益率 = `利益額 / 売価 × 100`
- ROI = `利益額 / 総コスト × 100`

商品Aの期待表示:
- 利益額: `835円`
- 利益率: `46.41%`
- ROI: `86.62%`
- 内訳に `送料（ネコポス）`、`梱包材（封筒/袋）` が表示される

### 2-4. 保存
1. 計算後に表示される `保存` ボタンを押します。  
2. 中央通知 `保存しました。` が表示されます。  
3. 自動で履歴画面（`/profit-history.html`）へ移動します。

## 3. 履歴画面の使い方
### 3-1. 一覧確認
- 保存した商品が時系列で表示されます（新しいものが上）。
- 商品名、売価、利益などを行ごとに確認できます。

### 3-2. その場編集
1. 編集したい行の `編集` を押します。  
2. その行の中に入力フォームが展開します。  
3. 値を修正して `保存` を押します。  
4. 中央通知で更新結果を確認します。  

例:
- `商品A` を `商品A改` に変更
- `販売予定価格` を `1899` に変更

### 3-3. 削除
1. 削除対象の行で `削除` を押します。  
2. 確認モーダル（はい/いいえ）で `はい` を選択。  
3. 行が削除され、通知が表示されます。  

## 4. 設定画面の使い方
### 4-1. 先頭ボタン行
- 左: `設定保存`（設定を確定）
- 右: `マニュアル`（利益計算マニュアル画面へ）

### 4-2. 表示設定
設定可能項目:
- 入力フォームの文字寄せ（左詰め/右詰め）
- 結果表示の文字寄せ（右詰め/左詰め）
- 内訳エリアの文字詰め（右詰め/左詰め）
- 内訳エリアの文字揃え（左揃え/右揃え）
- 利益率表示（ON/OFF）
- ROI表示（ON/OFF）
- ロケール
- 通貨コード

### 4-3. 送料候補の追加
1. `送料設定` の `＋` を押す。  
2. 入力行に `名前` と `価格` を入力。  
3. `追加` を押す。  
4. リストに1行で追加される。  

### 4-4. 梱包材候補の追加
手順は送料と同じです。  

### 4-5. 候補の編集/削除
- 編集: 行内でフォーム化して保存
- 削除: 確認モーダルで確定

### 4-6. 設定の確定
1. 変更後に `設定保存` を押します。  
2. 中央通知 `設定保存しました。` を確認します。  
3. 再読み込み後も反映されていれば保存成功です。  

## 5. 位置変更モード
### 5-1. 開始
1. ホーム上部の `位置変更` を押します。  
2. ボタン名が `位置変更保存` に変わります。  
3. row左側に3点ハンドルが表示されます。  

### 5-2. rowの移動
1. 移動したいrowの3点ハンドル付近を長押し。  
2. そのまま上下へドラッグ。  
3. 指を離すと新しい位置に配置されます。  

### 5-3. sectionの移動
- 入力セクションと結果セクションを上下で入れ替えできます。
- 先頭/末尾にいるsectionは無効ボタンになります。

### 5-4. 保存
1. `位置変更保存` を押します。  
2. 通知 `位置変更を保存しました。` を確認します。

## 7. 通知仕様
- すべてアプリ内通知（画面中央）で表示。
- ブラウザ標準 `alert/confirm` は使わない。
- 確認系はアプリ内モーダルを使用。

## 8. よくある確認ポイント
### 8-1. `保存` が出ない
- `計算` を実行していない可能性があります。
- 入力エラー時は先に入力値を見直してください。

### 8-2. 候補を追加したのに反映されない
- 設定画面で候補追加後、`設定保存` を押しているか確認。

### 8-3. 位置変更が戻る
- `位置変更保存` を押していない可能性があります。
