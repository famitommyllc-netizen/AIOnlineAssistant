# Requirements
- Updated: 2026-03-09 21:52:28 JST
- Purpose: 機能要件/非機能要件/受け入れ条件を定義する

## 1. 機能要件（現行）
- チャット画面からミニアプリへ誘導できること。
- tasks/memos/number-tool/profit の各機能が単体で利用できること。
- 利益計算は `計算 -> 保存` フローを提供し、履歴で編集/削除できること。
- 設定画面から表示や候補値を保存できること。

## 2. 機能要件（次フェーズ）
- ログイン認証（セッション認証）を導入すること。
- 全業務データをユーザー単位で分離すること。
- APIはログインユーザーのデータのみ返すこと。
- 外部公開前提で最低限のセキュリティ設定を満たすこと。

## 3. 非機能要件
- スマホ優先で操作しやすいUIを維持すること。
- ログ/バックアップ手順が運用可能であること。
- 主要操作で即時通知（保存完了/失敗）が表示されること。
- 機能追加時に既存UI共通仕様を崩さないこと。

## 4. 受け入れ条件（抜粋）
- チャット/各ミニアプリが起動し、主要操作でエラーにならない。
- 利益計算の計算結果、保存、履歴編集が一連で成立する。
- 設定保存が再読込後も反映される。
- 将来フェーズでは `user_id` 分離がAPI/DBの全テーブルで確認できる。

## 5. スコープ外（現時点）
- AI API本実装の品質改善。
- 地図連携による移動履歴自動取得。
- ネイティブアプリ化（iOS/Androidストア配布）。
