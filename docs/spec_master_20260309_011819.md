### Chat UI Layout (LINE/ChatGPT準拠の固定レイアウト)
- [23] ヘッダー固定、フッター固定、中間のみスクロール。
- [24] スクロール対象は #chatLog.chat-log-full のみ。
- [25] 追加でチャット領域を囲う内側カードは作らない（NG条件を排除済み）。
- [26] メッセージはユーザー右寄せ、秘書左寄せ。

- [30] モバイル時もMENUは横幅100%にせず、右側へ追加ボタン余白を確保。

### Chat Initial / Archive Behavior (省データ)
- [31] 画面表示用の初期秘書文言はローカル合成（intro_local）で保持。
- [32] 過去メッセージはサーバー側で日次アーカイブ（logs/history/YYYY-MM-DD.jsonl）へ退避。
- [33] 当日画面には「保存済み痕跡」メッセージを表示。
- [34] 痕跡メッセージには「前日の履歴を表示」ボタンを付与。
- [35] チャット上端までスクロールした場合、未読込日を自動ロード（LINE風遡り読み込み）。
- [36] 履歴読み込み時はスクロール位置を維持してジャンプを防止。

### Chat Intent / Mode
- [37] mode: normal / task_create / memo。
- [38] タスク作成で task_create に切替。
- [39] メモ / メモ作成で memo に切替。
- [40] 通常モード / モード終了で normal に戻す。
- [41] normal時の案内は秘書口調 + 主要アプリボタン（大項目のみ）。
- [42] 画面呼び出し系は曖昧表現で意図判定し、遷移ボタン付き返答を返す。

### Task Flow
- [43] チャット文から候補（件名/担当/期限/通知）を生成。
- [44] 候補はチャット内 承認/編集/見送り で確定。
- [45] 承認で taskNo 自動採番して tasks へ保存。
- [46] 未完了の間は通知判定ループで継続通知。
- [47] タスク管理画面で完了/再開/編集/削除/ソートを実装。

### Memo Flow
- [48] memoモード中の発話は notes へ保存。
- [49] メモ一覧で編集/削除/ソート可能。

### Number Tool
- [50] タイトル + 数値を保存。
- [51] KPI（合計/件数/平均）算出。
- [52] 履歴編集/削除/全消去。
- [53] Section/Row順序を保存・再現。

### Profit Tool (Current Final)
- [54] 入力: 商品名/原価/手数料%/送料/梱包材/売価/その他。
- [55] 出力: 利益額/利益率/ROI/詳細内訳。
- [56] 金額系は 円 後置、手数料は %。
- [57] 利益額・利益率・ROI は各1row、項目名と値を同一行表示。
- [58] KPIはロック済み（太さ・1row崩れ防止のCSS固定ルールあり）。
- [59] 計算後に保存ボタンを表示、保存時に履歴ページへ遷移。
- [60] 通知UIはブラウザalert/confirmではなくアプリ内通知/確認ダイアログ。
- [61] 位置変更保存時も通知を表示（中央強調）。

### Profit History (Latest Fix)
- [62] 履歴の編集は新規登録へ遷移しない。
- [63] 履歴行内でホーム同等フォームを展開し、その場で更新可能。
- [64] 更新は PATCH /api/tools/profit/records/:id を使用。
- [65] 削除はアプリ内confirm（はい/いいえ）で実施。

### Notification UX
- [66] 共通通知は public/app-feedback.js。
- [67] showNotice は画面中央表示・強調トースト。
- [68] confirm はアプリ内モーダル（標準confirm非依存）。
- [69] 計算/保存/設定保存/削除/更新/位置変更保存 で通知表示。
