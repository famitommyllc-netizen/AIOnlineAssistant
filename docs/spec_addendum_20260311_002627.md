# Spec Addendum
- Saved At: 2026-03-11 00:26:27 JST
- Base Spec: `docs/spec_master_20260309_025258.md`
- Purpose: ベース仕様との差分だけを短く固定する

## 1. Profit Tool 差分
- 入力セクションの `保存フォルダ（選択）` を廃止。
- 結果セクションに `保存先` 選択を配置。
- 計算後にのみ `保存先 + 保存` を表示。
- 保存完了/クリア時は保存コントロールを非表示に戻す。

## 2. Profit History 差分
- 商品ごとのフォルダ移動UIを停止（実装を一旦無効化）。
- フォルダ編集ボタン押下で編集フォームが確実に起動するよう修正。

## 3. Profit 設定差分
- `前回計算結果の復元` 設定を追加。
- OFF時は利益計算画面を初期表示で開始する。

## 4. デプロイ準備差分
- `package.json` の `start` は `node server.js` を満たす。
- `server.js` は `process.env.PORT || 3000` を満たす。
- `.git` は未初期化（GitHub push前に `git init` が必要）。
- `.gitignore` は `.env`/`*.log` を含む形へ更新済み。
