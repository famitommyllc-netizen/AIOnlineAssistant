# Google検索機能（無料枠）セットアップ手順
- Saved At: 2026-03-09 01:55:30 JST
- Target App: `chatbot`（チャット画面）
- Purpose: AI未搭載でGoogle検索リンクを返す機能の設定手順

## 1. 機能概要
- チャットで検索指示を送ると、Google Custom Search JSON API を呼び出してリンク一覧を返します。
- APIキー未設定時は、設定画面へ誘導するガイドメッセージを返します。
- 想定指示例:
  - `ガンプラ塗装法についてランキング10〜20前後のサイトリンクを教えて`
  - `フリマ 梱包 コツ を検索して`
  - `旅行 保険 おすすめ リンク教えて`

## 2. 事前に必要なもの
- Google Cloud の API Key
- Programmable Search Engine の CX（検索エンジンID）
- Custom Search JSON API を有効化済みのプロジェクト

## 3. アプリ側の設定場所
- 画面: `/settings.html`
- セクション: `Google検索設定（無料枠）`
- 入力項目:
  - `Google検索機能を有効化`（ON）
  - `Google API Key`
  - `Custom Search Engine ID (CX)`
  - `既定の取得件数`（1〜20）

## 4. 保存後の動作確認
1. 設定を保存
2. チャット画面へ戻る
3. 次の文を送信
   - `ガンプラ塗装法についてランキング10〜20前後のサイトリンクを教えて`
4. 期待結果
   - 検索結果カードが表示される
   - 各結果に `順位付きボタン / URL / snippet` が表示される
   - ボタン押下で新しいタブに遷移

## 5. 仕様メモ
- 範囲指定の解釈:
  - `10〜20` のような範囲表現を優先
  - 指定がない場合は設定の既定件数を使用
- 取得上限:
  - 本実装では最大50位相当まで
- エラー時:
  - API未設定 / 上限超過 / APIエラー時は設定画面誘導メッセージを返却
