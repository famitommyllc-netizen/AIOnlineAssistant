# ERP EntryForm 現行仕様スナップショット（2026-04-08）

この文書は `apps/erp/src/gas/EntryForm.html` を中心とした、現時点の実装仕様の固定メモです。  
目的は「現在仕様の保存」「後続改修時の差分基準化」です。

## 1. 画面構成
- 固定ヘッダー + スクロール本体 + 固定フッター構成。
- 画面状態は `entry / confirm / result` の3状態。
- 固定ヘッダータイトルは画面状態連動で切替。

## 2. 入力モード
- 商品・経費・ポイント・共通項目はステージ入力UIで編集。
- ステージ入力は候補サジェスト、戻る/確定、閉じるボタンを持つ。
- 日付はステージ内で `YYYYMMDD` 表示と date picker 同期を実施。

## 3. 商品入力
- 商品行は追加/削除可能（1行目は削除対象外）。
- 行内入力値:
  - 商品
  - 基準売価
  - 個数
  - 個別値引き
  - ポイント/割引
  - 経費
  - 支払方法（個別モード時）
- 計算値:
  - 原価
  - 単価
- 外税ON/OFF、個別モードON/OFFに連動して再計算。

## 4. 経費・ポイント
- フッター操作で経費/ポイント入力エリアの表示切替。
- 分配モードと個別モードを保持。
- 未使用時は確認画面・完了画面で非表示化する分岐あり。

## 5. 最終確認画面
- 既定は縦並びレイアウト。
- 商品明細は主行 + メタ行構成。
- 共通情報の日付表示は `yyyy/mm/dd`。
- 集計は商品数に単位（点）を付与して表示。

## 6. 表示設定UI
- 右サイドパネル表示。
- 役割別設定（h1/h2/th/値/補助ラベル/ヘッダー/フッター/注記/ボタン等）。
- 数値入力中心で即時反映。
- 表示設定テンプレ機能:
  - テンプレ選択（候補検索 + 候補選択）
  - 適用
  - テンプレ保存
  - スプレッドシート保存（サーバー側）

## 7. 商品入力テンプレ
- 商品入力テンプレは別機能として実装。
- 選択/保存/削除が可能。
- 適用時は入力値を上書き反映し、再計算する。

## 8. 登録処理と出力
- 登録本体は `registerEntries`。
- 印刷/PDF出力は共通サービスへ分離済み。
- 現在設定は「登録時自動出力オフ（generateOnRegister: false）」。

## 9. 非同期ステータス表示
- 長時間処理向けの共通ステータス表示を導入:
  - `Now Loading...`
  - `現在保存中...`
  - `保存しました`
- 主な `google.script.run` 呼び出しに接続済み。

## 10. rev管理
- `EntryForm.html` / `style.css.html` の rev 文字列を画面ヘッダーに表示。
- UI反映確認時のキャッシュ判定と識別に使用。
