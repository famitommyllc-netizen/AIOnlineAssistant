# Architecture
- Updated: 2026-03-20 02:03:51 JST

## 1. 構成
- Presentation: HTMLダイアログ（EntryForm, ProductRegister, EcperienseForm）。
- Application: GAS関数（main.gs, serch.gs, expenseForm.gs）。
- Data: Google Spreadsheet（商品情報, 在庫表, 経費）。

## 2. 処理責務
- `main.gs`: メニューとダイアログ起動。
- `serch.gs`: 商品検索、商品登録、仕入登録。
- `expenseForm.gs`: 経費候補取得、経費登録。

## 3. 拡張方針
- 採番ロジックを専用関数へ分離（仕入番号、仕入伝票番号）。
- マスタ管理APIを追加（仕入先、支払い方法、経費項目）。
- 経費配賦ロジックを仕入確定前に適用する。
- シート列定義を定数化して列ズレを防ぐ。
