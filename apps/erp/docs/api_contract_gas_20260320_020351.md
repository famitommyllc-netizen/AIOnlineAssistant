# API Contract (GAS)
- Updated: 2026-03-20 02:03:51 JST

## 1. UI起動
- `showEntryForm()` -> EntryFormダイアログ表示
- `showProductRegister()` -> ProductRegisterダイアログ表示
- `showSalesForm()` -> SalesFormダイアログ表示
- `showExpenseForm()` -> ExpenseFormダイアログ表示
- `showDashboard()` -> Dashboardダイアログ表示

## 2. 商品関連
- `searchProduct(keyword: string): Array<[productNo, name]>`
- `registerNewProduct(productInfo: object): {msg: string, name: string}`

## 3. 仕入関連
- `registerEntries(entryList: Array, commonInfo: object): string`

## 4. 経費関連
- `getExpenseItems(): string[]`
- `registerExpense(info: object): string`

## 5. 追加予定API
- `searchSuppliers(keyword)`
- `searchPayments(keyword)`

- `allocateExpenseByCostRatio(entryList, expenseList)`
