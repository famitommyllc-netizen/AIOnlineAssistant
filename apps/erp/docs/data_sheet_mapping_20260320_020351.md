# Data Sheet Mapping
- Updated: 2026-03-20 03:36:40 JST
- Note: 本ファイルは初版。最新版は `data_sheet_mapping_20260320_033640.md` を参照。

## 1. 商品情報シート（registerNewProduct）
- A: 商品番号
- B: JAN
- C: 商品名
- D: カテゴリ
- E: メーカー
- F: ブランド
- G: サブ
- H: 希望小売価格
- I: 備考
- J: 登録日
- K: 検索名
- L: 読み仮名
- M: 想定売価

## 2. 在庫表シート（registerEntries）
- A: 仕入No
- B: 仕入日
- C: 商品番号
- D: 商品名
- E: 提示金額
- F: ポイント/割引
- G: 経費按分
- H: 原価
- I: 在庫数
- J: 単価
- K: 仕入先
- L: 支払い方法
- M: 売上日
- N: 売上金額
- O: 販売場所
- P: 利益
- Q: 想定売価
- R: 想定利益
- S: 仕入伝票番号

## 3. 経費シート（expenseForm.gs）
- A: 日付
- B: 内容
- C: 金額
- D: メモ
- E: 登録日
