# 入力欄内カレンダーアイコン再利用パターン
- Updated: 2026-03-31 JST
- Status: 採用済み

## 1. 目的
- 日付入力で、カレンダーアイコンを入力欄の内側に自然に見せる。
- 見た目はボタン感を消し、入力欄の一部として扱う。
- 他画面でも同じ見た目を再利用できるようにする。

## 2. 採用方針
- 見えるアイコンは SVG を使う。
- クリック導線は `button` 側で持つ。
- 補助の `type="date"` は同期用として残してよいが、押下の主導権は見えるボタン側に寄せる。
- アイコンは入力欄そのものの中央ではなく、右端のアイコン配置エリア内で縦中央に置く。

## 3. スタイル方針
- ラッパー: `.entry-input-stage-input-wrap.is-date`
- アイコン領域: `.entry-input-stage-date-hitarea`
- 見えるアイコンボタン: `.entry-input-stage-date-button`
- SVG: `.entry-input-stage-date-icon`

### 固定ポイント
- 入力欄の右パディングを十分に確保する。
- アイコン領域は `top: 0; bottom: 0; display: flex; align-items: center;` で縦中央化する。
- ボタン背景、角丸、影は外して、入力欄に溶け込ませる。
- アイコンサイズは、入力欄に対して小さすぎないことを優先する。
- 区切り線を入れる場合は、アイコン領域の左に薄く入れる。

## 4. 操作方針
- 「見た目」と「操作」は分離してよい。
- ただし、押せない状態を避けるため、見える要素側から確実に日付ピッカー起動関数へ到達できる構造を優先する。
- 透明な補助 input を前面に重ねる方式は、環境差で無反応になりうるため注意する。

## 5. 今回の適用先
- `src/gas/EntryFormB.html`
- `src/gas/style.css.html`

## 6. 再利用時の確認項目
- 1回で開くか
- アイコンがアイコン配置エリア内で縦中央か
- アイコンが小さすぎないか
- モバイル時に押下領域が十分か
