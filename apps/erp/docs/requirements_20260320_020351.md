# Requirements
- Updated: 2026-03-20 02:03:51 JST

## 1. スコープ
- GAS + Spreadsheetで、仕入・商品・経費・売上の登録と参照を行う。
- 本版はまず受領コード準拠の再現と、仕入/経費周辺の要件完成を優先する。

## 2. 機能要件（現状）
- `onOpen()` でカスタムメニューを追加する。
- 商品検索 `searchProduct(keyword)`。
- 商品登録 `registerNewProduct(productInfo)`。
- 仕入登録 `registerEntries(entryList, commonInfo)`。
- 経費候補取得 `getExpenseItems()`。
- 経費登録 `registerExpense(info)`。

## 3. 機能要件（追加実装）
- 仕入入力時に経費項目を追加可能にする。
- 経費原価を商品原価割合で自動均等配賦する。
- 仕入先/支払い方法は検索選択を基本とする。
- 未登録入力値は各マスタへ自動追加する。
  - 商品
  - 経費
  - 仕入先
  - 支払い方法
- 仕入保存単位で1つの仕入番号を採番する。
- 仕入商品の各行に仕入番号を付与する。
- 仕入伝票番号と仕入番号は別体系で管理する。
- スプレッドシート番号体系を参照して採番・記録する。

## 4. 非機能要件
- 原本コードは `backup/gas_source_locked_*` を正本とし改変しない。
- 入力エラー時はユーザーが原因を把握できるメッセージを表示する。
- 採番と配賦は再現可能なルールで実装し、検証手順を保持する。

## 5. 入力UI統一ルール追記
入力UIは全てテーブル形式（1行入力型UI）で実装する。
仕入入力の「商品入力」を基準UIとし、全画面これに統一する。

複数入力の可能性がある項目は「+行追加・削除」を実装する。
単一入力項目は1行固定とし、行追加は表示しない。

既存UIは順次統一し、新規機能も必ずこのルールに従うこと。

## 6. 仕入登録要件の追記（2026-03-22）
- 仕入登録は、商品明細を複数行入力し、ポイント/経費を按分して在庫表へ登録する。
- 仕入伝票PDFとバーコードPDFを保存する。
- 仕入登録の共通項目として、`仕入場所` と `仕入方法` を要件に追加する。
