# OCR機能 アイデアメモ

## 1. 複数枚レシートの連続処理

複数のレシート画像を一括選択し、1枚ずつ順番に処理する機能。

**フロー：**
1. 複数画像を一括選択
2. 1枚目を処理 → 確認画面表示 → ユーザーが修正 → 登録
3. 登録完了後、自動で2枚目の確認画面を表示
4. 全枚完了まで繰り返し

**ポイント：**
- 確認・修正は1枚ずつ人間が行う
- 登録したら自動で次のレシートへ進む
- 何枚目/全何枚 の進捗表示をする

---

## 2. 初回店舗プロンプト保存機能

初めて読み込む店舗のレシートに対して、ユーザーにフォーマットを確認してプロンプトとして保存する機能。

**フロー：**
1. OCR後、店舗名を検出
2. 初回店舗の場合、はい/いいえ形式で質問
   - 「外税ですか？」→ はい/いいえ
   - いいえの場合は「内税ですか？」など修正を促す
3. 確認内容をその店舗専用のプロンプトとして保存
4. 次回から同じ店舗のレシートは保存済みプロンプトを自動適用

**メリット：**
- 精度が継続的に向上する
- 店舗ごとのレシートフォーマット差異に対応できる
