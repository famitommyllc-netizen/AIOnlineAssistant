# Requirements (Latest)
- Updated: 2026-03-24 17:18:07 JST

## 1. 運用目的
- GAS + Spreadsheetで、仕入・売上・在庫・経費を一元管理する。
- 仕入/売上の入力から、台帳反映、伝票保存、経営集計までを同一システム内で完結させる。

## 2. 仕入登録（最新要件）
- 仕入登録は、商品明細を複数行入力し、ポイント/経費を按分して在庫表へ登録する。
- 仕入登録時に、仕入伝票PDFとバーコードPDFを保存する。
- 仕入登録の共通入力項目は以下を必須管理対象とする。
- 仕入日
- 仕入場所
- 仕入方法
- 仕入先
- 支払い方法

## 3. 現実装との差分（明示）
- 実装済み:
- 仕入日
- 仕入先
- 支払い方法
- 未実装/要追加:
- 仕入場所
- 仕入方法
