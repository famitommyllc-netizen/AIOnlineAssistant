# Form Heading Structure Rules (Shared)

対象: 仕入入力・売上入力・今後のフォーム画面共通  
目的: 見出し構造の意味を統一し、UI実装とレビュー基準を揃える

## 1. Heading Roles
- `h1`: 画面タイトル（その画面の最上位タイトル）
- `h2`: セクション見出し
- `th`: テーブル列見出し

## 2. Non-Heading Roles
- 補助ラベル: 商品入力2段目（例: 単価 / ポイント / 経費 / 支払方法 / 外税）
- 入力値: `input` / `select` 等の入力コントロール
- 計算値: 表示専用の値（例: 原価、単価、集計値）

## 3. EntryForm Current Mapping
- `h1`
  - 仕入入力
  - 仕入登録 最終確認
  - 仕入登録 完了
- `h2`
  - 商品入力
  - 経費
  - ポイント/割引
  - 集計
  - 共通項目
  - 商品明細
  - 共通情報

## 4. Implementation Notes
- 見出しタグ置換時は、既存見た目維持のために `margin` などの最小CSS調整を同時実施する。
- 表示設定（フォント/行幅など）整理とは分離し、構造変更だけを先に行う。
