# ERP 実装メモ（3番号運用）
- 作成日: 2026-03-20 11:11:49 JST
- 対象: `chatbot/apps/erp/src/gas`
- 方針: 「棚卸評価方式（個別法/先入先出法/総平均法/移動平均法）」連動は今回**未実装**（完成後に検討）。

## 1. 今回の番号体系（3つ）
1. `商品個別番号`（在庫1行または個体ごと）
- 在庫表A列に保存
- 形式: `I00000001` の連番
- 設定の在庫ID方式で採番単位を切替
  - 明細単位: 1入力行につき1つ
  - 個体単位: 個数ぶん発行

2. `商品マスタ番号`（商品種類番号）
- 在庫表C列・商品情報A列に保存
- JAN未入力でも自動採番で運用可能

3. `仕入伝票番号`（取引単位）
- 在庫表S列に保存
- 形式: `SD-YYYYMMDD-仕入先-0001`

## 2. 実装済み内容
- 仕入保存時の `仕入No` 依存を除去。
- 保存ロジックを `商品個別番号 + 商品マスタ番号 + 仕入伝票番号` に統一。
- 商品候補をJAN対応に変更（JAN / 商品名 / 商品マスタ番号で解決）。
- 未登録商品入力時は商品マスタへ自動追加（商品マスタ番号も自動補完）。
- 伝票PDF/バーコードPDF/ブラウザ印刷表示の見出しを新番号体系へ統一。
- レポート（日次/月次）の見出し・データキーを新番号体系へ統一。

## 3. 在庫表ヘッダ（最新）
A: 商品個別番号  
B: 仕入日  
C: 商品マスタ番号  
D: 商品名  
E: 提示金額  
F: ポイント/割引  
G: 経費按分  
H: 原価  
I: 在庫数  
J: 単価  
K: 仕入先  
L: 支払い方法  
M: 売上日  
N: 売上金額  
O: 販売場所  
P: 利益

R: 想定利益  
S: 仕入伝票番号  
T: 商品個別番号一覧  
U: ラベル印刷状態

## 4. GASでシート変更を自動反映する手順（コピペ用）
Apps Scriptエディタで次を実行:

```javascript
function runSchemaUpdateNow() {
  var result = applyErpSchemaUpdates();
  Logger.log(JSON.stringify(result, null, 2));
}
```

- `runSchemaUpdateNow` 実行で、以下を自動整備します。
  - 在庫表ヘッダを最新仕様へ更新
  - 商品情報ヘッダを最新仕様へ更新
  - 売上伝票シート（`売上伝票`）ヘッダを作成
  - 設定シート初期化（存在時は維持）

## 5. 画面確認チェックリスト
1. 仕入入力で商品欄に `JAN / 商品名 / 商品マスタ番号` で候補選択できる。
2. 未登録商品名を直接入力して仕入登録すると、商品情報に自動追加される。
3. 登録後、在庫表Aに `I...` 形式の商品個別番号が入る。
4. 在庫表Sに `SD-...` の仕入伝票番号が入る。
5. 伝票印刷・バーコード印刷で「商品個別番号」「商品マスタ番号」が表示される。
6. 日次/月次レポートで同じ名称で表示される。
