# Product Overview
- Updated: 2026-03-20 02:03:51 JST
- App: ERP (GAS + Spreadsheet)
- Purpose: 仕入・商品・経費をGoogleスプレッドシートで一元管理する

## 1. 現状のアプリ概要
- カスタムメニューから `仕入登録` `商品登録` `売上登録` `経費登録` `ダッシュボード` を起動する。
- 実体として受領済みコードで確認できるのは、仕入登録・商品登録・経費登録。
- データはスプレッドシートの `商品情報` `在庫表` `経費` シートに保存される。

## 2. 現状で実行できる主要機能
- 商品検索（商品番号/JAN/商品名/検索名/読み仮名）。
- 商品新規登録（JAN下4桁 or 乱数4桁で商品番号生成）。
- 仕入リスト作成、ポイント按分、外税加算、在庫表への一括登録。
- 経費登録（内容候補のdatalist補完あり）。

## 3. これから実装する主要機能
- 経費原価を商品原価割合に応じて自動配賦。
- 仕入先/支払い方法/商品/経費の検索選択と未登録値の自動追加。
- 仕入番号の採番体系（仕入伝票番号と分離）を整備。
- 商品単位で仕入番号を付与し、シート番号ルールと連動。
