## 5. 実データ検証シナリオ
### シナリオA: 仕入登録
1. メニュー `仕入登録` を開く
2. 商品を2件以上登録（検索追加 + 手入力追加を混在）
3. ポイント/経費を入力
4. 共通項目入力後、`最終確認へ`
5. 最終確認で `戻って編集` を1回試す
6. `登録して伝票作成`

期待結果:
- 仕入番号 `Pxxxxxx` が採番される
- 仕入伝票番号 `SD-YYYYMMDD-仕入先-xxxx` が採番される
- 在庫表G列に経費按分、H列に原価が記録される
- 伝票PDFが指定フォルダに保存される
- 画面の `伝票を印刷` で印刷プレビュー可能

### シナリオB: 日次/月次レポート
1. メニュー `日次/月次レポート` を開く
2. 日次で当日を集計
3. 月次で当月を集計
4. `印刷` と `PDF保存` を実行

期待結果:
- 仕入/売上/経費明細が表示される
- 集計に総額・営業利益・利益率・減価率・経費率が表示される
- PDFが指定フォルダに保存される

4. 遠隔印刷はPDF共有運用（自動遠隔印刷は外部印刷サービス連携が必要）
