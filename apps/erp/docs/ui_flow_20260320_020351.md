# UI Flow
- Updated: 2026-03-20 02:03:51 JST

## 1. 仕入登録
1. キーワード入力して商品検索
2. 検索結果から商品選択
3. 提示金額と個数を入力してリストへ追加
4. 必要に応じて編集/削除/同商品追加
5. ポイント/割引合計を入力し按分
6. 税率選択後、外税加算
7. 共通項目（仕入日/仕入先/支払い方法）を入力
8. 一括登録で在庫表へ保存

## 2. 商品登録
1. 商品情報を入力
2. 登録実行
3. 商品情報シートへ1行追加

## 3. 経費登録
1. 日付/内容/金額/メモを入力
2. 登録実行
3. 経費シートへ1行追加

## 4. 追加予定UI
- 仕入画面で経費行を複数入力
- 仕入先/支払い方法/経費の検索選択
- 未登録値の自動マスタ追加
- 仕入番号と仕入伝票番号の表示
