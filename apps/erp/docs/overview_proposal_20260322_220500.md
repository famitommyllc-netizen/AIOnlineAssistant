# ERP 概要提案 v1
- Created: 2026-03-22 22:05:00 JST
- Status: Draft (要確定)

## 1. 目的
- GAS + スプレッドシートで、仕入・売上・在庫・経費を一元管理する業務アプリを構築する。

## 2. 対象業務
- 仕入登録
- 売上登録
- 経費登録
- 日次/月次レポート
- 伝票印刷/PDF保存

## 3. ID体系（3番号）
- 商品個別番号: 在庫1レコード単位
- 商品マスタ番号: 商品種類
- 伝票番号: 仕入/売上単位

## 4. UI方針
- 全入力画面をテーブル型1行入力で統一する。
- 複数入力可能な項目は `+行追加/-削除` を表示する。
- 単一項目は1行固定とする。

## 5. 仕入ロジック
- 商品明細は複数行入力。
- ポイントと経費は `按分モード` / `個別入力モード` を切替可能にする。
- 最終確認は別ページ表示とし、`戻って編集` で修正可能にする。
- 登録後に印刷確認モーダルを表示する。

## 6. 売上ロジック
- 未売上在庫候補から選択して一括売上登録する。
- 売上履歴は `売上伝票` シートへ追記する。
- 在庫反映方式は次のどちらかで固定運用する。
- 在庫0化
- 売上数減算

## 7. 候補マスタ方針
- `支払い方法候補` と `販売場所候補` は別タブ管理とする。
- 候補の追加/削除はUIから行えるようにする。
- 既存データは互換移行可能とする。

## 8. 出力
- 仕入伝票PDF・バーコードPDFをDrive保存する。
- 伝票は印刷可能とする。
- バーコードは将来運用も見据えて継続する。

## 9. 保守機能
- シートヘッダ自動整備、売上済み在庫補正などのメンテ関数を保持する。

## 10. 販売前提
- 将来の単体販売を想定し、設定/マスタ/伝票/集計を機能分離して拡張可能な構成にする。

## 11. 確定が必要な項目
1. 売上在庫反映方式: 在庫0化 / 売上数減算
2. 候補マスタ分離範囲: 支払い方法・販売場所のみ / 仕入先・経費も含め全分離
3. 商品個別番号方式: 明細単位 / 個体単位 / 設定で切替
4. 最終確認画面: 現在の別ページ型 / 伝票レイアウト寄り
5. MVP範囲: 仕入優先 / 仕入+売上同時
