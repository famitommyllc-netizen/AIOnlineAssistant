# ERP Mini App

## Purpose
仕入・売上・在庫・経営管理を一体で扱うERPミニアプリ。
将来の単体販売・別リポジトリ化を前提として、このディレクトリ配下に実装と資料を集約する。

## Directory
- `public/`: 画面・クライアント資産
- `src/`: サーバー/業務ロジック
- `data/`: アプリ固有データ
- `docs/`: 仕様・運用ドキュメント
- `specs/`: 要件/テスト仕様
- `progress/`: 進捗記録
- `logs/`: 実行ログ
- `backup/`: バックアップ
- `config/`: 設定ファイル

## Policy
- 以後、このERPのコード・仕様・進捗は `apps/erp/` 配下に保存する。
- 互換運用が必要な場合のみ、親アプリ側（`chatbot`）に導線を追加する。
