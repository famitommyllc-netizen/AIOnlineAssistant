利益計算アプリ マニュアル

商品Aの実例を使って、入力から保存・履歴編集・設定変更まで丁寧に確認できます。

1. 事前準備

1) サーバー起動: cd /Users/masamitomioka/workspace/chatbot -> node server.js 2) ブラウザで http://localhost:3000/apps/profit/public/profit-tool.html を開く 3) ヘッダーに MENU / 履歴 / 設定 / 位置変更 / × があることを確認

2. 商品Aで計算する（実例）

入力値: 商品名: 商品A 原価: 550 手数料（%）: 10 送料: ネコポス（185円） 梱包資材代: 封筒/袋（50円） 販売予定価格: 1799 その他: 0 手順: 1) 上記を入力 2) 「計算」を押す 3) 通知「計算しました。」を確認 4) 結果エリアを確認

3. 商品Aの期待結果

手数料額: 1799 x 10% = 179.9（表示上は 180円） 総コスト: 550 + 179.9 + 185 + 50 + 0 = 964.9 -> floor 964円 利益額: 1799 - 964 = 835円 利益率: 835 / 1799 x 100 = 46.41% ROI: 835 / 964 x 100 = 86.62% 内訳には ・送料（ネコポス） ・梱包材（封筒/袋） が表示されます。

4. 保存と履歴編集

保存: 1) 計算後に出る「保存」を押す 2) 通知「保存しました。」を確認 3) 履歴ページに自動遷移 履歴編集: 1) 対象行の「編集」を押す 2) その行内でフォームが開く 3) 値を変更し保存 4) 通知で更新結果を確認

5. 設定画面の使い方

先頭ボタン行: ・設定保存 ・マニュアル 変更できる内容: ・入力フォームの文字寄せ ・結果表示の文字寄せ ・内訳エリアの文字詰め / 文字揃え ・利益率表示 / ROI表示 ・ロケール / 通貨 送料・梱包材: 1) 「＋」で入力行を表示 2) 名前と価格を入力して「追加」 3) 行ごとに「編集」「削除」 最後に「設定保存」で確定

6. 位置変更モード

開始: ヘッダーの「位置変更」 row移動: 3点ハンドル長押し -> ドラッグ section移動: 上下ボタンで入替 終了: 「位置変更保存」で確定 位置変更中は MENU / 履歴 / 設定 / × は押せません。

7. チャットからの呼び出し（曖昧表現可）

利益計算: 「利益計算」「メルカリ利益」「フリマの利益」 利益設定: 「利益設定」「送料設定」「梱包設定」 利益履歴: 「利益履歴」「計算履歴」 利益マニュアル: 「利益計算マニュアル」「利益の使い方」 マニュアル一覧: 「マニュアル」「取説一覧」
