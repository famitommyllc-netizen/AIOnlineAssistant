# 利益計算アプリ 詳細マニュアル
- Saved At: 2026-03-09 01:31:43 JST

- Scope: 実運用向け手順（計算・保存・履歴編集・設定・位置変更・チャット呼び出し）

## 1. アプリ概要
- 利益計算アプリは、フリマ/ECの商品単位損益を素早く試算するためのミニアプリ。
- 入力値: 商品名、原価、手数料率、送料、梱包資材代、販売予定価格、その他コスト。
- 出力値: 利益額、利益率、ROI、詳細内訳。
- `保存` 実行後は履歴ページへ遷移し、保存データの編集/削除が可能。

## 2. 画面構成
### 2-1. ホーム（利益計算）
- URL: `/profit-tool.html`
- ヘッダー: `MENU / 履歴 / 設定 / 位置変更 / ×`
- 主領域:
  - 入力セクション（`#profitForm`）
  - 結果セクション（`#profitResultSection`）
- フッター固定はなく、ページ全体スクロール。

### 2-2. 履歴
- URL: `/profit-history.html`
- 保存済み商品の一覧。
- 各行で `編集 / 削除` を提供。
- 編集は別画面遷移でなく、その場フォーム展開で更新。

### 2-3. 設定
- URL: `/profit-settings.html`
- 表示設定 + 送料候補 + 梱包材候補の管理。
- 先頭操作行は2カラム:
  - 左: `設定保存`（約70%）
  - 右: `マニュアル`（約30%）

### 2-4. マニュアル
- 利益計算専用: `/profit-manual.html`
- マニュアル一覧: `/manuals.html`

## 3. 基本操作フロー
### 3-1. 計算のみ
1. ホームで項目を入力。
2. `計算` ボタンを押下。
3. 結果エリアに `利益額 / 利益率 / ROI / 内訳` を表示。
4. 中央通知で「計算しました。」表示。

### 3-2. 保存
1. 計算完了後に表示される `保存` ボタンを押下。
2. `POST /api/tools/profit/calc` で保存。
3. 通知「保存しました。」表示後、履歴ページへ遷移。

### 3-3. 履歴編集
1. 履歴行の `編集` を押下。
2. 同行内にフォームが展開。
3. 保存で `PATCH /api/tools/profit/records/:id` を実行。
4. 通知で更新結果を表示。

## 4. 入力項目仕様
- 商品名: 任意（空でも可）
- 原価: 数値（0以上）
- 手数料（%）: 数値（0以上、小数可）
- 送料/梱包資材: 設定候補から選択
- 販売予定価格: 数値（0以上）
- その他: 数値（0以上、初期値0）

## 5. 計算結果仕様
- 利益額: `floor(salePrice - totalCost)` 相当で表示。
- 利益率: `profit / salePrice * 100`
- ROI: `profit / totalCost * 100`
- 表示文言注記: `※利益額は小数点以下を切り捨て表示`
- 内訳は複数行で表示。送料/梱包材は選択名称を括弧付き表示。

## 6. 設定機能
### 6-1. 表示設定
- 入力フォームの文字寄せ: 左詰め/右詰め
- 結果表示の文字寄せ: 右詰め/左詰め
- 内訳エリアの文字詰め: 右詰め/左詰め
- 内訳エリアの文字揃え: 左揃え/右揃え
- 利益率表示: ON/OFF
- ROI表示: ON/OFF
- ロケール、通貨コード

### 6-2. 候補管理（送料/梱包材）
- `＋` 押下で入力行を展開。
- `名前 + 価格` 入力後 `追加` で候補登録。
- 候補行ごとに `編集 / 削除` を提供。
- 削除はアプリ内確認モーダル（はい/いいえ）。

### 6-3. 保存
- `設定保存` で `PUT /api/tools/profit/options` を実行。
- 成功時は通知表示 + 再読込でサーバー状態と同期。

## 7. 位置変更モード
- 開始: ヘッダー `位置変更`
- 終了/保存: ヘッダー `位置変更保存`
- row移動:
  - 3点ハンドル長押しでドラッグ開始
  - 入力row/結果rowを並び替え
- section移動:
  - 入力セクションと結果セクションを上下入替
  - 端では上/下ボタンが自動無効化
- 位置変更中のガード:
  - `MENU / 履歴 / 設定 / ×` は押下不可
  - 入力欄等は編集不可（移動操作優先）

## 8. 通知仕様（アプリ内）
- ブラウザ標準 `alert/confirm` は不使用。
- `public/app-feedback.js` を利用:
  - `showNotice`: 画面中央の目立つ通知
  - `confirm`: アプリ内確認ダイアログ
- 対象操作例: 計算、保存、設定保存、編集保存、削除、位置変更保存

## 10. API一覧（利益計算関連）
- `GET /api/tools/profit`
- `PUT /api/tools/profit/options`
- `POST /api/tools/profit/preview`
- `POST /api/tools/profit/calc`
- `PATCH /api/tools/profit/records/:id`
- `DELETE /api/tools/profit/records/:id`

## 11. 運用上の注意
- 通貨表示・整列は設定保存後に反映確認する。
- 候補編集と設定保存は別操作。候補追加後は設定保存も実行すること。
- 位置変更後は必ず `位置変更保存` を押して確定する。
- 履歴編集後は通知表示で成功/失敗を確認する。
