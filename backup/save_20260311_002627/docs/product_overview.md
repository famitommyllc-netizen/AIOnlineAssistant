# Product Overview
- Updated: 2026-03-09 21:52:28 JST
- Project: chatbot
- Purpose: このアプリが「何を解決するか」を最短で理解するための概要

## 1. アプリ概要
- 本アプリは「秘書チャット」を入口に、複数の業務ミニアプリを横断利用できるWebアプリ。
- 現在は Node.js の単一アプリ（`server.js`）として稼働。
- 画面はチャットを司令塔とし、タスク、メモ、数値集計、利益計算へ遷移して使う。

## 2. 主要価値
- 曖昧な指示をチャットで受け、必要な画面へ誘導できる。
- 日常運用で使う機能を一箇所にまとめ、操作を統一できる。
- ミニアプリを段階的に追加しやすい構造を目指す。

## 3. 現在の主要機能
- チャット（司令塔）: モード制御、画面呼び出し、ガイド表示。
- tasks: タスク作成/編集/完了/削除/通知運用。
- memos: メモ保存/一覧/編集/削除。
- number-tool: 合計/件数/平均の数値集計。
- profit: 利益計算、履歴、設定（サブ機能構成）。

## 4. 対象ユーザー
- まずは個人利用者（1ユーザー運用）。
- 将来的に複数ユーザー運用へ拡張予定。

## 5. 現在の制約
- 認証未導入（アクセス制御なし）。
- データは `data/store.json` のファイル保存。
- インターネット本番公開前提のセキュリティ設計は未完。

## 6. これからの方向性（確定方針）
- モノリス + モジュール分割を採用。
- 認証は1つ、DBは1つ、機能はミニアプリ単位で分割。
- 全業務データに `user_id` を持たせてユーザー分離する。
- チャットは司令塔に限定し、業務ロジックは各ミニアプリへ寄せる。
