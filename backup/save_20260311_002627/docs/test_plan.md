# Test Plan
- Updated: 2026-03-09 21:52:28 JST
- Purpose: 回帰を防ぎながら機能拡張するための確認観点

## 1. スモークテスト（毎回）
- サーバー起動:
  - `node server.js` で起動成功
- 主要ページ表示:
  - `/`, `/tasks.html`, `/memos.html`, `/number-tool.html`, `/profit-tool.html`
- 主要API応答:
  - `/api/state`, `/api/tools/profit`, `/api/tools/number`

## 2. 機能テスト
### Chat
- ミニアプリ誘導が動作する
- モード開始/終了が正しく反映される

### Tasks
- 作成/編集/完了/削除
- ソート/表示更新

### Memos
- 保存/一覧/編集/削除
- ログメモ/個別メモの挙動

### Number Tool
- 追加/編集/削除/全消去
- 合計/件数/平均が一致

### Profit
- 計算結果が式通り
- 保存後に履歴反映
- 履歴編集/削除
- 設定保存反映

## 3. UI回帰テスト
- KPI 1row崩れがない
- モバイル表示で主要ボタンが操作可能
- 位置変更モードの誤操作防止が維持される

## 4. 次フェーズ（認証導入後）追加
- 未ログインアクセスの拒否（401）
- 別ユーザーのデータ参照不可
- user_id 条件漏れの有無確認

## 5. 不具合時の記録
- 再現手順
- 期待結果/実結果
- 画面ログとサーバーログ
- 対象runログファイル
