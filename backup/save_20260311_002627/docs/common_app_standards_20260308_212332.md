# Common App Standards
- Saved At: 2026-03-08 21:23:32 JST
- Purpose: 次のミニアプリを作る時に、同一の操作性・見た目・実装方針を再利用するための共通仕様
- Scope: chatbot配下で開発するWebミニアプリ共通

## 1. 用語定義
- 共通項目の正式名: `共通仕様`（実装/運用では `標準仕様` も可）
- UI寄りの呼称: `デザインシステム` または `UIガイドライン`
- 実装寄りの呼称: `共通コンポーネント規約` / `UI実装規約`

## 2. モバイルヘッダー標準
- 配置は常に同一レイヤーで横並び。
- 基本順: `MENU` / `履歴` / `設定` / （ホームのみ `位置変更`） / `×`。
- `×` は常時表示、右端、真円ボタン。
- サブ画面で `×` を押すと当該アプリのメインへ戻る。
- メイン画面で `×` を押すと、連携先（将来は秘書チャット）へ戻る。

## 3. 位置変更モード標準
- 位置変更はモード切替で有効化する。
- モード中は入力欄の編集を無効化し、移動操作に集中させる。
- モード中は iOS の選択メニュー（コピー等）を抑止する。

### 3.1 Section移動
- Section移動は `↑` `↓` で実施。
- 最上段は `↑` 非活性、最下段は `↓` 非活性。
- 非活性は視認可能な見た目で表現する。
- 移動時はゆっくりした視覚アニメーション（浮き上がり→入替）を付与する。

### 3.2 Row移動
- Row移動は `長押しドラッグ&ドロップ`。
- モード中のみ、各Row左側に縦3点ハンドルを表示。
- 3点はテキストではなくデザイン要素（同系色の単色）で描画。
- 3点はRow内で自然に表示し、項目名との間隔を確保する。
- 3点はrowの上下中央に表示する（中央基準）。
- ドラッグ中はRow全体が浮き上がり、移動対象が明確に分かること。
- 固定行（注記行/保存ボタン行など）は移動対象に含めない。
  - 固定行には3点ハンドルを表示しない。

## 4. チャット連携標準
- チャットから曖昧表現で各アプリ呼び出し可能にする。
- 通常モードは「秘書案内 + 主要アプリボタン表示」を基本にする。
- 主要アプリボタンは大項目のみ表示（詳細設定は隠す）。

## 5. 表示/可読性標準
- スマホ優先で設計し、必要に応じてPCで拡張。
- 数字入力は16px以上（iOSズーム回避）。
- 重要KPIは入力欄より視認性を一段高くする。
- 長文明細は折り返し設計し、カテゴリ単位で改行して可読性を確保。

## 6. データ永続化標準
- 並び順（Section/Row）はUI設定として保存し、再読込で再現する。
- 設定値は画面ごとに namespace 化（例: `calculators.profit.ui`）する。
- 履歴系データは編集/削除を標準搭載。

## 7. 実装チェックリスト
- ヘッダー順序/サイズ/色が標準通りか。
- `×` の遷移先が画面種別で正しいか。
- 位置変更モード中に入力できないか。
- Rowハンドルが左側に統一され、3点が同色デザインか。
- 上下端のSection移動ボタンが正しく無効化されるか。
- 並び順が保存され、再起動後に維持されるか。

## 8. KPIカード厚み上限（固定ルール）
- 利益計算の `利益額 / 利益率 / ROI` カードは、次の高さ上限を超えない。
  - デスクトップ基準: `min-height: 56px`
  - スマホ基準: `min-height: 38px`
- この上限は固定運用とし、今後の変更でこれ以上太くしない。
- 3カードは同一高さルールで統一する。

## 9. Profit KPIロック運用
- `public/styles.css` の以下トークンを固定運用する。
  - `--profit-kpi-min-h: 56px`
  - `--profit-kpi-min-h-mobile: 38px`
  - `--profit-kpi-value-size-mobile: 20px`
- 目的: `利益額 / 利益率 / ROI` の見た目が太くなる再発を防止する。
- 上記の値は、ユーザーの明示指示がない限り増やさない。

## 10. Profit KPI崩れ防止（最終ロック）
- KPI（利益額/利益率/ROI）は `項目名 + 値` の1row固定。
- `styles.css` の FINAL LOCK ブロックで、以下を `!important` で固定する。
  - `kpi-inline-row` の `display:flex` / `justify-content:space-between`
  - KPIの `white-space: nowrap`
  - KPIカード高さトークン参照（PC/モバイル）
- `inputAlign=right` のときは、KPIも右寄せ連動する。

## 11. Profit結果セクション固定行ルール
- 丸め注記（rounding）は結果セクション最上部の固定行とする。
- 丸め注記は最初のKPI行（利益額）の直前に配置し、移動モードでも順序を変えない。
- 保存ボタン行（actions）は内訳行に紐づく固定行とし、独立移動させない。
- 結果row並び替え対象は `profitValue / marginRate / roiRate / resultText` のみとする。

## 12. Profit KPIハードロック（回帰防止）
- `利益額 / 利益率 / ROI` はID指定（`#profitValueRow/#marginRateRow/#roiRateRow`）で固定する。
- 固定内容:
  - 1row表示（`display:flex`, `nowrap`）
  - 高さ固定（`min-height = max-height`）
  - ラベル/値とも折り返し禁止
- モバイル時も同様に固定し、モバイル用トークンで高さを揃える。
- 将来改修時も、上記3rowの固定ルールは削除しない。
