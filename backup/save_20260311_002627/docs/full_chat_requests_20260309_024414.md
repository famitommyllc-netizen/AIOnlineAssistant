## 1. 開始時の要件（最初期）
- [1] `workspace/chatbot` 配下で叩き台を作成。
- [2] Webアプリとして実装。
- [3] AI APIは将来設定可能にし、当初はAIなし運用。
- [4] 曖昧表現（日時/優先度）を整形して保存。
- [5] リマインダー機能。
- [6] タスク機能（完了まで通知）。
- [7] 返答口調を秘書/執事トーンに統一。

## 2. 起動・運用トラブル対応
- [8] `npm` が無い環境のため `node server.js` 起動へ統一。
- [9] ポート/起動確認ログを常時参照する運用へ移行。
- [10] `/api/state` 肥大化（大量メッセージ/通知履歴）問題を認識し、日次アーカイブ方式へ拡張。
- [11] 履歴は当日表示と分離、必要時読み込みに変更（軽量化）。

## 3. チャットUI・UX要件
- [12] LINE型左右寄せ（秘書=左、ユーザー=右）。
- [13] 長文時もPC/スマホで読みやすい折返し。
- [14] ヘッダー固定 + フッター固定 + 中央チャットのみスクロール。
- [15] チャット領域を二重箱で囲わない（1つながり画面）。
- [16] 入力欄と送信は1行（LINE風）。
- [17] モード終了ボタンはフロート表示、通常モードでは非表示。
- [18] 通常モード時は秘書の案内文 + 主要アプリ導線（大項目のみ）。
- [19] メニューはPCでも集約（MENU起点）、アイコン重なり防止。

## 4. タスク機能の要件蓄積
- [20] 承認ボタンはチャット会話内に表示。
- [21] `期限整形→入力` は自動化。
- [22] 可能な範囲で件名/担当を自動抽出。
- [23] 編集ボタンを承認横に配置、口語で編集指示可能。
- [24] 担当者抽出精度課題が継続議題（AI導入前提で改善予定）。
- [25] 通知指定を自然文で受付（例: 3日前/1日前/当日朝10時/3時間前）。
- [26] タスク管理画面に完了・編集・削除・ソートを実装。
- [27] 完了ボタンでステータス変更する動作を確定。
- [28] タスク番号付与（taskNo）を実装。

## 5. メモ機能の要件蓄積
- [29] メモモードをチャット命令で起動。
- [30] メモ保存時は内容を見やすく返答し、メモ一覧ボタン導線を表示。
- [31] メモ一覧画面を作成。
- [32] メモ一覧に編集/削除/ソートを実装。
- [33] 記録方式を2系統へ分離:
  - ログメモ（追記）
  - 個別メモ（分割）
- [34] 記録終了ボタン押下まで、投稿ごとに改行追記。
- [35] 最新要件: ログメモは1件固定、個別メモは1記録モード1件。
- [36] 最新要件: ログメモを一覧最上部固定 + 背景色変更で強調。
- [37] 最新要件: モード中は曖昧表現命令を抑止（設定ON/OFF）。

## 6. 利益計算アプリ（最重要サブ機能）
- [38] 利益計算アプリを独立運用可能な形で整備。
- [39] 入力/結果/履歴/設定/マニュアルの画面分離。
- [40] 保存済み履歴のその場編集（新規化しない）を実装。
- [41] 数値・単位表示（円/%）の見やすさ改善を反復調整。
- [42] `利益額/利益率/ROI` の1row維持と視認性を固定。
- [43] 行/セクション位置変更（長押しドラッグ + 保存）を実装。
- [44] 位置変更中の操作制御（押せる/押せないUI）を調整。
- [45] 送料/梱包材設定を追加UIで管理（追加/編集/削除）。
- [46] 削除はアプリ内確認モーダル（yes/no）で統一。
- [47] 計算・保存・設定保存時の中央通知を実装。
- [48] マニュアルページをアプリ内常設、設定画面から即表示可能。
